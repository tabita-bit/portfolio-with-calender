# Portfolio with Calendar

A personal portfolio website built with HTML, CSS, and vanilla JavaScript. Includes an about section, project showcase, an interactive calendar widget, and a contact section.

## Features
- Responsive navigation with smooth-scroll links
- About section with profile photo and bio
- Project cards showcasing other lab work
- Fully functional calendar (month navigation, highlights today's date)
- Contact section

## Tech Stack
- HTML5
- CSS3
- JavaScript (DOM manipulation, Date object)

## Project Structure

```
Portfolio/
├── image/           # Directory containing images used in the portfolio.
│   └── woman.jpg    # Profile image used in the portfolio.
├── README.md        # Documentation and information about the project.
├── index.html       # Main HTML file containing the portfolio structure and content.
└── style.css        # Stylesheet responsible for the layout, colors, typography, responsiveness, and overall design.
```

## Run Locally
Just open `index.html` in any browser. No build step or dependencies required.
